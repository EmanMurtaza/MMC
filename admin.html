Connect Supabase

The admin panel needs your Supabase project.

  1. Create a project at supabase.com.
  2. Open SQL Editor, paste the contents of supabase/schema.sql and run it.
  3. Open Project Settings → API. Copy the Project URL and the anon public key into config.js.
  4. Open Authentication → Users → Add user and create your admin email and password.
  5. In Authentication → Sign In / Providers, turn off "Allow new users to sign up".
